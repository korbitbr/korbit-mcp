# Política de segurança

## Reportando uma vulnerabilidade

**Não abra issue pública** para vulnerabilidades.

Reporte por e-mail: **seguranca@korbit.com.br** (ou contato@korbit.com.br). Inclua: descrição, passos de reprodução, impacto estimado e, quando possível, prova de conceito. Você receberá confirmação em até 2 dias úteis.

## Escopo

- Aplicações e bibliotecas publicadas nesta organização (docs, SDK, MCP server, skills)
- A API e a infraestrutura de produção da Korbit

Fora do escopo: ataques de spam volumétrico, falta de rate limits em serviços de terceiros, relatórios sem evidência técnica.

## Divulgação coordenada

Pedimos até 90 dias para correção antes de qualquer publicação. Reportadores responsáveis recebem crédito (se desejarem) no changelog de segurança.
